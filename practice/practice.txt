Задание 1. Модуль «Зоопарк»
Шаг 1. Создайте файл zoo.py. Напишите в нём три функции:

hours() — выводит на экран 'Открыто 9-17 ежедневно'
animals() — возвращает список ['тигр', 'медведь', 'пингвин']
ticket(age) — принимает возраст и возвращает цену билета:

до 7 лет — 0
от 7 до 17 — 200
18 и старше — 500

Шаг 2. Создайте файл main_zoo.py. Импортируйте модуль zoo и:

вызовите zoo.hours()
выведите список животных
выведите цену билета для возрастов 5, 12 и 25

Ожидаемый вывод:
Открыто 9-17 ежедневно
Животные: ['тигр', 'медведь', 'пингвин']
Билет (5 лет): 0 руб.
Билет (12 лет): 200 руб.
Билет (25 лет): 500 руб.

Задание 2. Модуль «Калькулятор»
Шаг 1. Создайте файл calc.py с четырьмя функциями:

add(a, b) — возвращает сумму
subtract(a, b) — возвращает разность
multiply(a, b) — возвращает произведение
divide(a, b) — возвращает результат деления (если b == 0, возвращает строку 'Ошибка: деление на ноль')

Шаг 2. Создайте файл main_calc.py. Импортируйте модуль calc под псевдонимом c и проверьте все четыре функции, включая деление на ноль.
Ожидаемый вывод:
10 + 3 = 13
10 - 3 = 7
10 * 3 = 30
10 / 3 = 3.3333333333333335
10 / 0 = Ошибка: деление на ноль

Задание 3. Модуль «Конвертер температур»
Шаг 1. Создайте файл temperature.py с двумя функциями:

to_celsius(f) — принимает градусы Фаренгейта, возвращает Цельсий: (f - 32) * 5 / 9
to_fahrenheit(c) — принимает Цельсий, возвращает Фаренгейт: c * 9 / 5 + 32

Шаг 2. Создайте файл main_temp.py. Импортируйте функцию to_celsius под псевдонимом в_цельсий (через from ... import ... as). 
Переведите 32°F, 72°F и 212°F.

Ожидаемый вывод:
32°F = 0.0°C
72°F = 22.2°C
212°F = 100.0°C
