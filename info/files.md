# Урок-лекция: Ввод и вывод данных в файлы в Python

## 1. Введение

**Зачем нужны файлы?**
*   **Проблема:** Программы работают в оперативной памяти (RAM). Она быстрая, но данные исчезают при выключении питания.
*   **Решение:** Жесткие диски (файлы). Они медленнее, но данные сохраняются навсегда (стойкое хранилище).
*   **Цитата:** «Огромная ошибка — делать выводы, не имея необходимой информации» (Артур Конан Дойль). Файлы — это способ сохранить информацию для выводов.

**Открытие файла**
*   Основная функция: `open(filename, mode)`.
*   Возвращает объект файла (`fileobj`).
*   **Режимы доступа (первая буква):**
    *   `'r'` — чтение (по умолчанию).
    *   `'w'` — запись (создает файл или перезаписывает существующий!).
    *   `'x'` — запись только если файла не существует (безопасно).
    *   `'a'` — добавление в конец файла.
*   **Тип файла (вторая буква):**
    *   `'t'` — текстовый (по умолчанию).
    *   `'b'` — бинарный (байты).

> Обратите внимание на режим `'w'`. Если вы откроете существующий файл в этом режиме, его содержимое будет уничтожено. Будьте осторожны!

## 2. Запись в файл

**Способы записи**
1.  **Метод `write()`:**
    *   Записывает строку.
    *   Не добавляет пробелы или переносы строк автоматически.
    *   Возвращает количество записанных байт/символов.
2.  **Функция `print()`:**
    *   Может писать в файл через аргумент `file=`.
    *   По умолчанию добавляет пробелы между аргументами и `\n` в конце.

**Пример кода**
```python
# Создаем стихотворение
poem = '''There was a young lady named Bright,
Whose speed was far faster than light;
She started one day
In a relative way,
And returned on the previous night.
'''

# Запись через write()
fout = open('relativity', 'wt')
fout.write(poem)
fout.close()

# Запись через print() (добавит лишний перенос строки в конце!)
fout = open('relativity2', 'wt')
print(poem, file=fout)
fout.close()
```

> Помните, что после работы с файлом его нужно закрыть методом `close()`, чтобы данные физически записались на диск. Но есть способ лучше, о нем позже.

## 3. Чтение из файла

**Способы чтения**
1.  **`read()`:** Читает весь файл целиком (осторожно с большими файлами!). Можно указать количество символов.
2.  **`readline()`:** Читает одну строку за раз.
3.  **`readlines()`:** Возвращает список строк.
4.  **Итерация:** Самый простой способ — использовать файл в цикле `for`.

**Пример кода (Чтение)**
```python
# Чтение всего файла
fin = open('relativity', 'rt')
poem = fin.read()
fin.close()

# Чтение по строкам (итератор)
fin = open('relativity', 'rt')
for line in fin:
    print(line, end='') # end='' чтобы не дублировать переносы строк
fin.close()
```

> При чтении пустая строка `''` означает конец файла. В цикле `for` это обрабатывается автоматически.

## 4. Безопасность и Бинарные файлы

**Менеджер контекста `with`**
*   **Проблема:** Если программа упадет до `close()`, файл может остаться открытым.
*   **Решение:** Конструкция `with`. Файл закроется автоматически даже при ошибке.
*   **Синтаксис:**
```python
with open('relativity', 'wt') as fout:
    fout.write(poem)
# Файл закрыт автоматически здесь
```

**Бинарные файлы и позиция**
*   **Бинарный режим:** Используйте `'b'` (например, `'wb'`, `'rb'`). Работаете с байтами (`bytes`), а не строками.
*   **Позиция в файле:**
    *   `tell()` — текущее смещение в байтах.
    *   `seek(offset, origin)` — переход к позиции.
        *   `origin=0` (по умолчанию): от начала.
        *   `origin=1`: от текущей позиции.
        *   `origin=2`: от конца файла.

**Пример `seek`:**
```python
fin = open('bfile', 'rb')
fin.seek(-1, 2) # Переход к последнему байту с конца
bdata = fin.read()
```
