# Урок: Логирование ошибок в файл на Python

Вместо того чтобы использовать функцию `print()` для отладки, профессиональные разработчики используют **журналирование (logging)**. Это позволяет сохранять историю работы программы, отслеживать ошибки и понимать, что происходило перед сбоем, не засоряя экран лишним выводом.

## 1. Почему не `print()`?
*   **`print()`**: Выводит всё на экран, сложно отключить в готовой программе, нет информации о времени или уровне важности.
*   **`logging`**: Записывает в файл, имеет уровни важности (можно скрыть отладочные сообщения), добавляет метки времени и номера строк.

## 2. Базовая настройка
Для начала нужно импортировать модуль `logging` и настроить его. Самый простой способ — функция `basicConfig()`.

```python
import logging

# Настраиваем логирование: уровень DEBUG и имя файла
logging.basicConfig(level=logging.DEBUG, filename='my_program.log')

# Теперь сообщения будут записываться в файл my_program.log, а не на экран
logging.debug("Это отладочное сообщение")
logging.info("Программа запустилась")
logging.warning("Внимание: что-то не так")
logging.error("Произошла ошибка!")
logging.critical("Критический сбой!")
```

> По умолчанию уровень приоритета — `WARNING`. Если вы хотите видеть сообщения `debug` и `info`, нужно явно указать `level=logging.DEBUG`.

## 3. Уровни логирования
В Python есть 5 основных уровней важности сообщений. Используйте их правильно:

| Уровень | Функция | Когда использовать |
| :--- | :--- | :--- |
| **DEBUG** | `logging.debug()` | Детальная информация для отладки (значения переменных). |
| **INFO** | `logging.info()` | Подтверждение, что всё работает как ожидается. |
| **WARNING** | `logging.warning()` | Что-то неожиданное, но программа работает (например, закончилось место на диске). |
| **ERROR** | `logging.error()` | Из-за проблемы функция не выполнила действие. |
| **CRITICAL** | `logging.critical()` | Серьезная ошибка, программа не может продолжать работу. |

## 4. Запись в файл
Чтобы логи сохранялись после закрытия программы, укажите параметр `filename` в конфигурации.

```python
import logging

# Все логи будут сохраняться в файл error.log
logging.basicConfig(level=logging.ERROR, filename='error.log')

try:
    result = 10 / 0
except ZeroDivisionError:
    logging.error("Произошло деление на ноль", exc_info=True)
```
*Параметр `exc_info=True` автоматически добавит traceback (текст ошибки) в журнал.*

## 5. Форматирование сообщений
Вы можете настроить вид записи, чтобы видеть время, номер строки и уровень ошибки. Используйте переменные в строке формата:

*   `%(asctime)s` — дата и время.
*   `%(levelname)s` — уровень (ERROR, INFO...).
*   `%(lineno)s` — номер строки кода.
*   `%(message)s` — ваше сообщение.

**Пример**
```python
import logging

fmt = '%(asctime)s %(levelname)s %(lineno)s %(message)s'
logging.basicConfig(level=logging.DEBUG, format=fmt, filename='blue_ox.log')

logger = logging.getLogger('bunyan')
logger.error("Где моя другая клетчатая рубашка?")
```
**Результат в файле:**
`2014-04-08 23:13:59,899 ERROR 1 Где моя другая клетчатая рубашка?`

## 6. Создание собственного логгера
Для больших программ лучше создавать отдельные объекты-логгеры с именами. Это позволяет управлять ими независимо.

```python
import logging

logging.basicConfig(level='DEBUG')
# Создаем логгер с именем 'my_app'
logger = logging.getLogger('my_app')

logger.debug('Запуск процесса...')
```
Если имя содержит точки (например, `my_app.module`), это создает иерархию логгеров.

## 7. Практическое задание
Попробуйте выполнить следующее упражнение, чтобы закрепить материал:

1.  Создайте файл `task_log.py`.
2.  Настройте логирование в файл `task.log` с уровнем `DEBUG`.
3.  Напишите функцию, которая делит два числа.
4.  Если происходит ошибка (например, деление на ноль), запишите её в лог с уровнем `ERROR`.
5.  Если всё хорошо, запишите результат с уровнем `INFO`.
6.  Запустите программу дважды: один раз с корректными данными, второй раз с делением на ноль. Проверьте содержимое файла `task.log`.

**Пример решения:**
```python
import logging

logging.basicConfig(level=logging.DEBUG, filename='task.log', 
                    format='%(asctime)s - %(levelname)s - %(message)s')

def divide(a, b):
    try:
        result = a / b
        logging.info(f"Успешно: {a} / {b} = {result}")
        return result
    except Exception as e:
        logging.error(f"Ошибка при делении {a} на {b}: {e}")

divide(10, 2)
divide(5, 0)
```
